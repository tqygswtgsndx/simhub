## Overview

SimHub is the premier telemetry and dashboard platform for racing simulators, reading real-time game data from iRacing, ACC, Assetto Corsa, rFactor 2, F1, Dirt Rally, and dozens more to drive custom dashboards, motion rigs, Arduino LED strips, motion cancellation, and advanced HUD overlays. Thousands of community-shared dashboard profiles are available for every sim.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **SimHub** delivers the features you need in a clean, intuitive package.

> Official website: [simhubdash.com](https://simhubdash.com)

## Key Features

| Feature | Description |
|---------|-------------|
| **50+ Game Support** | Reads telemetry from over 50 racing sims and games |
| **Custom Dashboards** | Design dashboards with live gauges, graphs, and lap comparisons |
| **Hardware Output** | Drive Arduino LEDs, rev lights, and motion rigs from telemetry data |
| **Community Profiles** | Thousands of community dashboard designs available for free download |
